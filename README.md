# Zomato Delivery Operations Analytics

## Project Overview
This project analyses Zomato's food delivery operations using Python and SQL. The objective is to understand the factors associated with delivery time and identify opportunities to improve delivery efficiency.

## Business Problem
Food delivery platforms need to manage delivery time efficiently while considering factors such as delivery distance, road traffic, weather conditions and multiple delivery assignments.

This project investigates how these factors are associated with delivery time.

## Dataset
- **Dataset:** Zomato Delivery Operations Analytics
- **Source:** [Kaggle – Zomato Delivery Operations Analytics](https://www.kaggle.com/datasets/saurabhbadole/zomato-delivery-operations-analytics-dataset)
- **Target variable:** Time_taken (min)
